# 实验记录模板

用于未来记录的一致模板，不是新实验授权，也不生成假结果。

记录 Question、Setup、计算契约与来源、输入/输出、预设阈值、计时边界、warm-up/measured、顺序与种子、环境、验收标准。运行前 Result=NOT_RUN；实际运行后链接原始 JSON、哈希和核验，再写观察。

分别写当时状态、当前结论、失败记录、源码事实、实测观察和待验证解释。未知写 UNKNOWN/UNAVAILABLE/NOT_MEASURED，不用计划代替证据；历史失败不删除。
