# 五轮结果：收益、负向和不确定性

本文件提供逐轮绝对耗时和比值附录。先读方向性总结，再看每轮表，避免把最低单次结果当结论。

五次会话均通过当前合成契约：离线核验 5000 个采样时间戳、232985 个导出小输出。性能大矩阵由页面在线全量校验；离线没有完整大型 actual 数组，不能声称独立复算了每个大输出。

B 选定配置相对自身原配置在四组中五轮都改善，但尤其 M=1 不一定快于 A。M=128 的 D 选定配置两种量化都五轮改善。M=1 的 D 有方向反转及网格内差异；Q8 M=128 的 C 差异均在一个网格内，不能说稳定改善。

保留 Q4 M=1 D 原/选定比值范围 0.895833..1.04545、Q8 M=1 D 0.933333..1.095238，以及 Q8 M=128 C 0.986301..1.0625。精确值见共享表。没有根据这些结果改变配置，不从变化推断缓存、带宽或调度瓶颈。
