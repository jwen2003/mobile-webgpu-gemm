# 历史归档核验的范围

早期归档核验是当时证据集合的结果，不是全部后续实验的总验收。

原始记录、失败状态、验证 JSON 与哈希保持字节不变。当前双语整理另建文档检查结果，不覆盖既有核验记录。早期 Q8 未完成等陈述是历史状态，当前 Q4/Q8 五轮结论见报告及结果文档。

离线验证小用例全部导出输出、时间戳差和顺序；大型配置只导出了在线摘要及部分 reference，不能补造未导出的 actual。私有系统证据只发布派生数据与哈希。
