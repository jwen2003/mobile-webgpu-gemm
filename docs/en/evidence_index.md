# Evidence and publication-scope index

Evidence is kept once. Both languages reference the same JSON, verification records, and figures without copying or rewriting data.

results/raw stores published phone experiments, while results/analysis stores derivatives and verification. raw_sha256_manifest.json records historical raw hashes; stage_delivery_data.json supplies shared report tables. PROFILE002 shader sources are in results/analysis/profile002/shaders.

The original assignment is assignment/webgpu_adreno_assignment.pdf; summaries are not authoritative translations. Emails in updates, model weights, vendor resources, private system output, and temporary integrity snapshots are excluded from documentation publication. Byte-preserved historical Markdown snapshots retain contemporaneous states; their old links are historical text, not current navigation.
