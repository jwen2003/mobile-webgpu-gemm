# Experiment-record template

A consistent template for future records; it neither authorizes a new experiment nor creates invented results.

Record Question, Setup, contract/source, inputs/outputs, preset tolerances, timing boundaries, warm-up/measured counts, order/seeds, environment, and acceptance criteria. Before execution Result=NOT_RUN. After execution link raw JSON, hashes, and verification before reporting observations.

Separate contemporaneous status, current conclusion, failures, source facts, observations, and hypotheses. Use UNKNOWN/UNAVAILABLE/NOT_MEASURED where appropriate. Plans do not substitute for evidence and historical failures remain.
