# Scope of historical archive verification

Earlier archive validation covers the evidence set available then, not acceptance of all later experiments.

Raw records, failure states, verification JSON, and hashes remain byte-preserved. This bilingual reorganization creates separate documentation-check results rather than overwriting existing verification records. Earlier statements such as Q8 pending are historical; current Q4/Q8 repeat conclusions are in the report and results.

Offline checks validate all exported small outputs, timestamp differences, and orders. Large cases export online summaries and some reference records, not complete actual arrays; missing actuals cannot be reconstructed. Private system evidence is represented publicly by derivatives and hashes.
