Part 1: Baseline and Profiling (no optimization)
Task. Run Gemma E2B on an existing WebGPU stack, such as WebLLM, MediaPipe LLM Inference, or
Transformers.js. If E2B is not supported out of the box, use the closest Gemma variant and document why.
Do not optimize anything in this part.
Metrics to record
Run each metric at least 5 times and report the median and p95.

Profiling methods
 WebGPU timestamp-query for per-pass GPU timing.
 Chrome tracing and chrome://gpu for the pipeline view.
 Snapdragon Profiler for hardware counters, if available.
 adb shell dumpsys meminfo for memory.
Analysis
Identify the top 2-3 bottleneck kernels. Then classify the dominant bottleneck as one or more of: memory
bandwidth, compute, synchronization, kernel launch overhead, dequantization, poor occupancy. Justify each
classification with evidence.
Classification
Example evidence
Memory bandwidth
Achieved GB/s versus device peak; arithmetic intensity on a roofline
Compute
Achieved GFLOPS versus peak FP16/FP32 throughput
Synchronization
Barrier stalls; gaps between passes
Launch overhead
Wall time per token versus the sum of kernel times; many tiny dispatches

Part 2: Custom GEMM Kernel
Pipeline. Q4/Q8 weights, then dequantization, then matrix multiplication, then FP16 accumulation.
Kernel
Description
A
Baseline naive WGSL
B
Tiled GEMM using workgroup shared memory
C
Tiled with vectorized loads (vec4, packed u32)
D
Fused dequant + GEMM
Requirements
 Benchmark each kernel in isolation on Gemma's real layer shapes: the decode GEMV (M=1) and prefill
(M>=128).
 Sweep tile sizes and workgroup sizes.
 Report GFLOPS, effective GB/s, and correctness (max absolute error against an FP32 reference).
 Check support for the shader-f16 feature and provide a fallback if it is absent.
 Use proper timing: warm-up runs, many iterations, timestamp-query rather than CPU timers.
Deliverable
 A custom GEMM kernel that demonstrably beats the baseline GEMM on your target Adreno.
 A comparison table for kernels A-D.
 An explanation of why each variant is faster or slower.
 A reproducible benchmark harness (code, instructions, and raw results).
